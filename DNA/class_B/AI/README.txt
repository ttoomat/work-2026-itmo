CLASS B — OPA810 + VAS
Запуск SPICE-модели

Состав схемы: 2 операционных усилителя OPA810 и 11 транзисторов BJT.
Пример настроен на ёмкостную нагрузку 300 нФ.

1. СОДЕРЖИМОЕ

spice/circuit.cir       — соединения, номиналы, питание, входная волна и расчёт.
spice/model.lib         — макромодель OPA810.
spice/*.lib             — модели транзисторов и диодов.
spice/.spiceinit        — настройки совместимости PSpice.
spice/plot_results.py   — построение графиков из результатов ngspice.
class_b_lv_schematic.pdf — электрическая схема.
spice_to_kicad.csv      — соответствие обозначений SPICE и KiCad.

Все файлы внутри spice должны оставаться вместе, включая .spiceinit.
Симулятор запускается из каталога spice.

2. УСТАНОВКА И ЗАПУСК НА WINDOWS

Распаковать архив, например в D:\HV_review.
Скачать ngspice 47 для Windows 64-bit:
https://ngspice.sourceforge.io/download.html

Распаковать весь дистрибутив, например в D:\Spice64.
Одного EXE недостаточно: нужны также DLL и остальные каталоги дистрибутива.

Открыть PowerShell и выполнить, подставив свои пути:

Set-Location 'D:\HV_review\spice'
& 'D:\Spice64\bin\ngspice_con.exe' -b -o spice.log circuit.cir

Дождаться завершения команды. Проверить код завершения:

$LASTEXITCODE

Он должен быть 0. Посмотреть конец журнала:

Get-Content .\spice.log -Tail 15

Для самого расчёта Python не нужен.

3. ПОСТРОЕНИЕ ГРАФИКОВ

Установить Python, NumPy 2.x и Matplotlib. При необходимости использовать
отдельное окружение Python. В каталоге spice выполнить:

py -m pip install "numpy>=2" matplotlib
py .\plot_results.py

Скрипт читает data.txt, полученный от ngspice. Он не моделирует усилитель
самостоятельно и не сдвигает выходной сигнал относительно эталона.


4. РЕЗУЛЬТАТЫ

spice.log       — журнал расчёта и предупреждения.
data.txt        — исходные численные результаты ngspice с заголовками столбцов.
waveforms.png   — начальное установление и три последовательные волны.
last_pulse.png  — третья волна крупно: VIN, эталон/COM, ошибка и ток нагрузки.
waveforms.csv   — время, VIN, эталон, COM, ошибка и ток нагрузки.
quick_check.json — контрольные численные показатели третьей волны.

Повторный запуск перезаписывает результаты. Перед изменением номиналов
скопировать каталог spice в отдельную папку.
В минимальном архиве reference_run содержит пример результатов контрольного запуска.

6. КОНТРОЛЬ ПРАВИЛЬНОСТИ

Параметры: 300 нФ, силовое питание +50/-10 В, питание ОУ +8/-10 В,
температура 27 °C, начальное удержание 20 мкс, три волны по 27,5 мкс,
затем 10 мкс удержания; максимальный шаг 5 нс.
Третья волна: 75...102,5 мкс.

Контрольные значения третьей волны:
максимум модуля ошибки — около 4,99 В;
RMS ошибки — около 1,60 В;
минимум COM — около -4,73 В;
максимум COM — около 42,91 В.

Ошибка = COM - (17.92 * VIN - 2.8), без компенсации задержки.
RMS вычисляется по времени с учётом адаптивного шага SPICE.
Колебания на фронтах в этой версии сохраняются.

Известные предупреждения касаются неподдерживаемых служебных атрибутов
диодной модели Iave, Vpk, mfg, type и оформления комментария в библиотеке.
Ошибки timestep too small, unknown subckt, отсутствие модели или
незавершённый расчёт игнорировать нельзя. Старый data.txt может остаться
после неудачного запуска, поэтому проверять также свежий журнал.

7. ИЗМЕНЕНИЕ ЁМКОСТИ

В копии circuit.cir найти строку:

C3 load_node 0 3e-07

3e-07 Ф = 300 нФ. Для 20 нФ заменить значение на 20n,
для 100 нФ — на 100n. Повторить расчёт и построение графиков.
SPICE-элемент C3 соответствует C6 / TEST на схеме KiCad.

Этот пример выполняет transient одной нагрузки. Для получения запаса
по фазе требуется отдельный анализ петлевого усиления.

8. СОВМЕСТИМОСТЬ

Этот circuit.cir предназначен для ngspice. Команды .control и wrdata
нельзя без преобразования запускать в LTspice или TINA-TI.
Файл .cir является текстовым описанием схемы, а не её графическим чертежом.
