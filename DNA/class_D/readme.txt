  transient/COM_300nf.cir — основной нетлист полной переключательной петли;
  transient/COM_1nf.cir   — та же схема при минимальной нагрузке;
  ac/loop_300nf.cir и loop_1nf.cir — отдельный усреднённый анализ петли;
  models/                — все библиотеки, необходимые для запуска;
  reference/             — схема PDF, BOM и ранее полученные графики;
  provenance/            — происхождение и контрольные суммы файлов.
Файл .cir — текстовое описание схемы, возбуждения и команды расчёта.
Файлы .lib содержат модели компонентов. Одного .cir без models недостаточно.
JSON волны приложен для справки; все источники PWL уже записаны в нетлисте.


ПЕРВЫЙ ЗАПУСК В LTSPICE — ОСНОВНАЯ ВОЛНА
1. Распаковать ВЕСЬ архив, например в C:\COM_spice. Не открывать .cir из ZIP.
   Сохранить взаимное расположение transient, ac и models. Папка должна быть
   доступна для записи: LTspice создаст рядом с .cir файлы .raw и .log.
2. Открыть LTspice. File → Open → transient\COM_300nf.cir.
   Если файл не виден, выбрать тип Netlists или All files.
   Откроется текст: это нормально, схема .asc для расчёта не требуется.
3. Нажать Run в меню Simulate либо кнопку запуска на панели инструментов.
   Запускается только выбранный случай, без перебора нагрузок.
   Моделируется 49,1 мкс: подготовка 0…10 мкс и вся волна 10…49 мкс.
   На исходном компьютере этот случай занял около 16,6 минуты;
   время на другом ПК может отличаться. Не останавливать из-за медленного старта.
4. В окне графика выбрать Plot Settings → Add Trace / Add a Trace.
   Последовательно добавить выражения:
     V(head)-10       — COM на головке относительно системной GND;
     V(ref)-10        — эталонная волна относительно той же GND.
   Увеличить участок 10u…49u по оси времени. Это полный период 39 мкс.
5. Через Plot Settings → Add Plot Pane добавить отдельную панель:
     V(head)-V(ref)   — ошибка без компенсации задержки;
   ещё одну панель при необходимости:
     I(L1)           — ток выходного дросселя, амперы.
   Панель можно выбрать щелчком и затем добавить в неё нужную кривую.
6. Открыть SPICE Error Log через меню View. Штатное завершение содержит
   строку Total elapsed time. Также проверить, что RAW дошёл до 49,1 мкс.
   Одной строки в LOG недостаточно для оценки качества выходной волны.
   Сохранить .raw и .log, даже если расчёт остановился раньше.

ВАЖНО ПРО НОЛЬ НАПРЯЖЕНИЯ
В переходном нетлисте SPICE node 0 = физическая PGND = −10 В.
Системная земля sysgnd находится на +10 В относительно node 0.
Поэтому просто V(head) показывает COM со сдвигом +10 В.
Использовать V(head)-10: sysgnd не включён в сохранённый набор сигналов,
поэтому выражение V(head,sysgnd) может быть недоступно в готовом RAW.
